# ToothDex v1.7 — Pixel art & personnalisation de la maison

Cette version ajoute :
- 5 styles de sol (chêne miel, chêne foncé, bois rouge, pierre claire, carreaux)
- 6 papiers peints (crème, fleuri, bleu ciel, vert sauge, bleu nuit, briques)
- une personnalisation sauvegardée indépendamment pour chaque pièce (salon, chambre, cuisine, salle de jeux) et le jardin
- un rendu plus pixelisé pour les sols, les meubles et les décorations
- le déplacement tactile/souris des décorations achetées, avec sauvegarde de leur position

Les choix de décoration sont enregistrés dans la sauvegarde locale du navigateur. Les données de brossage, captures et Pokédex sont conservées.

Installation : remplacer les fichiers du dépôt GitHub Pages par le contenu de ce dossier. Le cache du service worker a été renouvelé pour forcer la mise à jour.
